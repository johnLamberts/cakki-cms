# Project: [Cakki CMS]

> ** HEADS UP: VIBE CODING IN PROGRESS**
> This project is being built with **high energy** and **flow state**. We are prioritizing momentum, "unique" features, and engineering joy over corporate rigidity.
> Expect rapid iteration, experimental commits, and a lot of caffeine.


## The Mission
We are building a **Visual SaaS CMS** that doesn't suck. 

Most CMSs are either "too simple" (Wix/Squarespace) or "too headless" (requires a PhD to edit a button). We are building the hybrid: **A Headless Core with a "God Mode" Visual Editor.** We give users **Full Control**—padding, margins, flexbox, data binding—without writing code, all while outputting clean, developer-friendly APIs.

## The "Vibe" Stack
We are using the tools that make us feel powerful. No bloat, just speed.

- **The Brain:** .NET 9 Web API (C#)
- **The Face:** React + TypeScript + Vite
- **The Brawn:** MySQL (JSON Hybrid Schema)
- **The Bodyguard:** YARP (BFF Pattern - No tokens in the browser!)
- **The Style:** TailwindCSS + Custom "Infinity" Canvas

## Key Features (The "Cool Stuff")

### 1. The Fortress (Security)
*Bank-grade security, but easier to manage.*
- **BFF Pattern:** No Access Tokens in `localStorage`. Ever. The backend holds the keys.
- **Biometric Auth:** Log in with FaceID/TouchID (WebAuthn).
- **Session Kill Switch:** Remotely nuke a session if things look sus.

### 2.  The Infinity Canvas (Visual Editor)
*Not your grandma's WYSIWYG.*
- **True Drag & Drop:** We drag actual React Components, not just HTML blobs.
- **In-Context Editing:** Click text to type. Click image to swap. Flow state editing.
- **The "Matrix" View:** Visual controls for Flexbox, CSS Grid, and the Box Model. If you know CSS, you have superpowers here.

### 3. The Schema Engine
*Database modeling for humans.*
- **Dynamic Content Types:** Create a "Blog Post" or "Product" definition on the fly.
- **Instant APIs:** You build the schema, we auto-generate the REST/GraphQL endpoints.
- **Hybrid Storage:** Relational SQL tables for metadata + JSON for flexibility.

### 4.  Advanced Governance
*Control freak friendly.*
- **Granular RBAC:** "Can Edit Text" vs "Can Break Layout."
- **Component Locking:** Lock the Header/Footer so the intern doesn't delete the logo.
- **Time Travel:** History rollbacks. Undo the chaos.

##  The Plan (Walking Skeleton Strategy)

We aren't building a monolith. We are building a skeleton and adding muscle.

- [ ] **Phase 3: The Brain** (Schema Builder & API Gen)
- [ ] **Phase 4: The Polish** (UI styling & "Vibe" checks)
